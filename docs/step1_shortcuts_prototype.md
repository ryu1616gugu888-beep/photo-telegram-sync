# Step 1: iOSショートカットによるプロトタイプ検証手順

コード不要で「写真追加→Telegram自動送信」の価値を検証するための手順。ここで感触を掴んでから
本格的なXcode実装(`dev/`)に進む。すべてユーザー本人のiPhone/Telegramアカウントで行う操作。

所要時間の目安: 15〜20分。

## 事前準備: Telegram Bot作成とトークン取得

1. iPhoneのTelegramアプリで `@BotFather` を検索して開始する。
2. `/newbot` と送信する。
3. Botの表示名(例: `My Photo Sync`)を聞かれるので入力する。
4. Botのユーザー名(例: `my_photo_sync_bot`、末尾は必ず `bot`)を聞かれるので入力する。
5. 成功すると「Use this token to access the HTTP API:」というメッセージとともに
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` のようなトークンが表示される。
   **このトークンは秘密情報。他人に見せたりコミットしたりしない。**

## 事前準備: 自分のchat_idを取得する

1. 作ったBotとのトーク画面を開き、何でもいいので1通メッセージを送る(例: `test`)。
2. Mac(またはiPhoneのブラウザ)で以下のURLを開く(`<TOKEN>` を実際のトークンに置き換える):

```
https://api.telegram.org/bot<TOKEN>/getUpdates
```

3. 返ってきたJSONの中の `"chat":{"id":123456789, ...}` の数値が自分の `chat_id`。これも控えておく。

(この2ステップはユーザー自身のTelegramアカウント認証情報のやり取りを伴うため、Claude Codeが
代行実行はしない。うまく取得できない場合はスクリーンショットを共有してもらえば手順の確認は手伝える。)

## Shortcuts(ショートカット)アプリでの自動化設定

1. 「ショートカット」アプリを開き、下部タブの「オートメーション」→ 右上の「+」→
   「個人用オートメーションを作成」を選ぶ。
2. トリガー一覧から **「写真」** を選択し、「写真が追加された時」を選ぶ。アルバムは
   「すべての写真」のままでよい(必要なら特定アルバムに絞ってもよい)。「次へ」。
3. 「アクションを追加」で **「URLの内容を取得」** を検索して追加する。
4. アクションの設定:
   - URL: `https://api.telegram.org/bot<TOKEN>/sendPhoto`(動画も試すなら別自動化で `sendVideo` を用意)
   - 方法: `POST`
   - リクエストボディ: 「フォーム」を選択し、以下のキーを追加
     - `chat_id` → 値に控えた chat_id を直接入力
     - `photo` → 値の種類を「ファイル」にして、直前の「ショートカット入力」(トリガーで渡された
       写真)を割り当てる
5. 最後に表示される「実行前に確認」のトグルを **オフ** にする(オンのままだと毎回通知確認が必要になり
   「自動」にならない)。
6. 保存する。

## 動作確認

1. カメラで適当に1枚撮影する、または写真アプリに1枚保存する。
2. 数秒〜数十秒後、Telegramの当該Botとのトーク(または自分の Saved Messages 設定次第)に写真が
   届けば成功。
3. 届かない場合によくある原因:
   - `chat_id` の桁や符号(グループチャットの場合は先頭に `-` が付く)を間違えている
   - トークンの前に `bot` を付け忘れている(`bot<TOKEN>` が正しい形)
   - 「実行前に確認」がオンのままで、通知をタップし忘れている
   - iOSの自動化がバックグラウンドで実行される条件(低電力モードなど)に引っかかっている

## 検証で見るべきポイント(本格実装に進むかどうかの判断材料)

- 実際にどれくらいの遅延で届くか(即時〜数分単位まで振れることがある)
- 連続撮影(バースト)時にレート制限で失敗しないか
- 動画・Live Photoを試した場合の挙動(`sendVideo` は別自動化が必要、Live Photoは静止画のみ届く点に注意)
- 「これで十分」と感じるか、「もっと確実に/もっと柔軟に」が必要でXcode実装に進むべきと感じるか

検証結果と所感は `docs/progress.md` に記録しておくと、次の実装フェーズにそのまま引き継げる。
