# 【下書き】短編動画台本2: 「2万枚の写真を移行した話」

想定尺: 30〜45秒。開発の裏話・信頼性訴求を軸にした台本(note記事のダイジェスト版として使える)

## 構成: フック(3秒)→ 実体験 → 学び→今回のアプリへの接続 → CTA

| 秒数 | 画面 | セリフ/テロップ |
|---|---|---|
| 0-3 | 「写真、2万枚移行した」というテロップをババーンと大きく | 「写真、2万枚移行しました」 |
| 3-10 | Google Takeoutのエクスポート画面、Pythonスクリプトが動いている様子(コード画面) | 「Google Photosから、自分でスクリプト書いてTelegramに全部移した」 |
| 10-18 | 「写真は原本のまま送る」「動画は再エンコードされない」など、テロップで小ネタを2〜3個テンポよく | 「原本の画質を保つには送り方にもコツがあった」 |
| 18-26 | アプリ画面に切り替え、「今すぐ同期」タップ | 「その知見を、"これから撮る写真"用のアプリにした」 |
| 26-34 | Telegramに写真が届く様子+「容量無制限」のテロップ | 「Telegramなら容量を気にせず預けられる」 |
| 34-40 | 開発者イメージ(顔出し不要、手元や画面のみでOK) | 「開発者はあなたの写真もパスワードも一切見れない設計」 |
| 40-45 | アプリロゴ | 「今は自分専用アプリとして開発中。続きはフォローして待っていてください」 |

## 撮影・編集メモ
- 実体験ベースの信頼性が武器。誇張表現(「バズった」「話題」等の事実確認できない煽り文句)は入れない。
- コード画面を映す場合、APIキー・トークン等の秘密情報が映り込まないよう必ず事前確認する。
